# Лабораторная № 1. Численные методы

Программа читает условие из текстового файла и печатает результат. Матрица с клавиатуры не вводится.

## Как запустить в Visual Studio Code

1. Откройте папку `NumericalMethods` в Visual Studio Code.
2. Откройте терминал: меню **Terminal → New Terminal**.
3. Запустите программу, передав путь к файлу с условием:

```bash
python3 lab.py examples/variants/01.txt
```

Другие примеры:

```bash
python3 lab.py examples/thomas.txt
python3 lab.py examples/iterative.txt
python3 lab.py examples/jacobi.txt
python3 lab.py examples/qr_complex.txt
```

NumPy для основного счёта не нужен. Он используется только в пункте 1.5, чтобы рядом напечатать `numpy.linalg.eigvals`, если пакет установлен.

## Где лежит каждый метод

| Пункт | Файл | Что делает |
| --- | --- | --- |
| 1.1 | `lu.py` | LU с выбором главного элемента в столбце, решение, обратная матрица, определитель |
| 1.2 | `thomas.py` | метод прогонки по трём диагоналям |
| 1.3 | `iterative.py` | простые итерации и метод Зейделя, эталон через своё LU |
| 1.4 | `jacobi_eigen.py` | метод вращений Якоби для симметрической матрицы |
| 1.5 | `qr.py` | QR-разложение Грама–Шмидта и QR-алгоритм |
| запуск | `lab.py` | читает файл и печатает результат |

Варианты 1–30 для LU лежат в `examples/variants/01.txt` … `30.txt`.
