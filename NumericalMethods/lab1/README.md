```bash
python3 lab.py examples/variants/01.txt
python3 lab.py examples/thomas/01.txt
python3 lab.py examples/iterative/01.txt
python3 lab.py examples/jacobi/01.txt
python3 lab.py examples/qr/01.txt
```

Номера примеров: LU `examples/variants/01.txt` … `30.txt`, прогонка `01`–`06`, итерации `01`–`10`, вращения и QR `01`–`30`.
